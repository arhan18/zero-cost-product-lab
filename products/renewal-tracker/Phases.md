# Phases — Renewal Tracker (BUILD-FIRST vertical slices)

## Phase 1 — Core renewal CRUD + Round 1 frontend foundation
Records (all PRD fields + uncertainty flag), add/edit/delete/archive, localStorage, ops
dashboard (hero + urgency groups + totals + owners), empty state + sample-data loader.
Gate: Human Gate 1 (Round 1 screenshots 390/768/1440, PASS required).

## Phase 2 — Reminder/notice logic
Notice-period → cancel-by computation, reminder offsets (60/30/7d) displayed per record,
urgency boundaries verified at edges, overdue/unsure treatments.

## Phase 3 — Calendar/export
CSV export + ICS export (renewal + cancel-by + reminders as events); import-sanity in
Google/Apple Calendar; search/filter if trivial.

## Phase 4 — Refinement + launch readiness
Design Rounds 2–5 per human gates, final QA (§16 checklist), distribution materials prepared
(not published without authorization). Then launch → observe per traction plan.
