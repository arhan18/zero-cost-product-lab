# Customer workflow — Scenica (canonical six steps, customer-facing)

## 01 — Pick a preset
Start from a production-ready visual system (layout grammar, typography, colors, spacing,
component + animation language, hero treatment, cinematic style, responsive behavior).
Our own original presets — never the reference product's names or compositions.

## 02 — Describe
Brand, business, audience, mood, atmosphere, visual style, sections, CTA, products/media,
desired cinematic behavior — with structured prompt assistance. Internally compiled into a
structured Site Brief (brand, industry, audience, tone, visual direction, sections, CTA,
media + motion + responsive requirements). Never one giant prompt.

## 03 — Generate
AI produces the cinematic keyframe / hero concept first; it sets palette, hero composition,
type treatment, hierarchy, motion direction, atmosphere — visual asset before page styling.

## 04 — Animate
Keyframe becomes motion via the cheapest effective medium (AI image-to-video, procedural,
CSS, shader, camera move, parallax). Engine chooses; live WebGL only when earned.

## 05 — Build
Motion becomes responsive experience: scroll-scrubbed frame sequences (primary cinematic
technique), video-backed sections, CSS/DOM motion, WebGL where spatial interaction is
essential, or hybrid — decided per section, not per site.

## 06 — Deploy
Preview URL → publish URL → optional custom domain → downloadable export (HTML/CSS/JS +
assets + frames/video + metadata) → status + rollback/versions. Portable by design; hosting
is a convenience, not a lock-in.
