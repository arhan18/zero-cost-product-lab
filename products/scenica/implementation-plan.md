# Implementation plan — Scenica (slice-first)

Slice 0 (prove the loop, no AI): hand-written site schema → renderer → sandbox preview →
publish → export. Exit: preview URL + ZIP from schema in <1 day.
Slice 1 (first intelligence): brief→plan→sections→stills→preview (capped, cost-logged).
Exit: 3 consecutive successful previews, measured costs within budget.
Then Phases.md 1–12 in order; each phase needs kill criteria + demo before the next starts.
Staffing: solo; AI-assist allowed for scaffolding, never for generated-output claims.
Estimates: Slice 0 (1–2d) → Slice 1 (3–5d) → editor (3–5d) → publish/export (2–3d) →
credits/billing (3–4d) → hardening/launch (1–2wk). First revenue-capable cut ≈ 4–6 weeks
solo at sustainable pace — hence BUILD verdict is slice-conditional, not whole-product.
