# Legal/IP — Scenica (considerations for counsel, not advice)

- Inspiration vs copying: category mechanics (brief→site→publish, credits) are not ownable;
  Draftly's code, branding, copy, preset names/compositions, and assets are OFF-LIMITS.
  This package contains zero of them (teardown paraphrased; presets original).
- Terms: AI-output disclaimer (no accuracy guarantees), acceptable use (no phishing/malware/
  infringing generations), credit terms (no rollover, failed-job refunds), pause-not-delete
  on lapse, age floor, governing law TBD.
- Privacy: minimal data, no training on user content without consent, 30-day purge on delete,
  subprocessor list (hosting, payments, email, model APIs).
- Ownership: user owns their brief, content, and exported site; we own platform + preset
  designs; media license terms must match the image/video provider's terms.
- Abuse/takedown: report flow, infringing-site suspension, DMCA agent/process before scale.
- Trademark: clear "Scenica" + mark search before launch; no reference to Draftly in marketing.
