# Outreach Protocol — Flat-Rate Status Pages (refugee wedge)

No outreach performed yet. This is the protocol; results to be recorded here when collected. No product exists — outreach is learning-only, no waitlists, no scarcity claims.

## TARGET

50 highly targeted contacts: solo/2–5-person indie SaaS founders, 100–1K users, no DevOps, showing UptimeRobot-free usage (badges, "monitored by" footers, IH/X bios) or commercial-monitoring complaints. Sources: r/SaaS, r/SideProject, r/microsaas, Indie Hackers, X build-in-public replies, AlternativeTo reviewer profiles. Never spam; participate where allowed, DM only where contact is welcome.

## MESSAGE (template, adapt per contact)

"Noticed you're on UptimeRobot free for [product] — heads-up their Dec 2024 terms ban commercial use. I'm researching a $12/mo flat status page with one-click UptimeRobot import + auto-updating custom-domain page, no seat/subscriber cliffs. Would you switch for that, or is free/manual fine? What would it need to do?"

## QUALIFICATION

In-ICP: commercial SaaS, currently free/manual monitoring, founder reachable. Out: hobby/non-commercial, enterprise (SSO/compliance needs), existing happy Instatus/Better Stack payers (note as objection data).

## QUESTION (core)

"What do you use for uptime/status today, and what would make you move it?"

## FOLLOW-UP

If interest: current setup details, monitor count, price sensitivity ($9 vs $12 vs $20), import/migration concerns, trust requirements for a new provider. If no: reason code (no problem / happy / free suffices / no trust / no time).

## SUCCESS SIGNALS (predefined)

WEAK: likes, views, "cool idea," complaints without action. MEDIUM: detailed reply, describes setup, asks when available. STRONG: asks to switch/test, shares setup, agrees to migration, states pricing preference, commits testing time. VERY STRONG: agrees to pay/pilot/design-partner.

## Threshold

50 contacts. Track: contacts, responses, problem confirmation, switching intent, trial intent, migration interest, pricing feedback, objections, rejections. Threshold frozen; smaller-but-stronger signals documented separately.
