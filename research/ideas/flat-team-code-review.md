# Idea Brief — Flat-Team Code Review

1. Product: AI code review for small teams at flat pricing (full-codebase context + ROI framing). 2. Category: CLONE + AI.
3. Why trending: Jun–Sep 2026 roundups (20 tools); CodeRabbit 2M+ repos, 13M PRs; Qodo 73.8% accept rate; agent-written code needs reviewers.
4. Target user: 2–10-dev teams drowning in AI commits. 5. Problem: per-seat $24–30/u/mo scales punitively; SonarQube complexity for 7M devs.
6. Existing products: CodeRabbit $24/u, Greptile/Qodo $30/u, Cursor Bugbot $40/u.
7. Clone/wedge: $49/mo flat team tier (5 devs pay $49 not $120–150) + BYOK option.
8. Distribution: dev communities, "coderabbit alternative/pricing" SEO, GitHub-adjacent directories.
9. MVP: PR webhook + diff review + inline comments on GitHub; 4–6 weeks.
10. AI margin: CONDITIONAL — full-codebase context is token-heavy; flat pricing requires quotas + BYOK escape hatch. Grade: INFERENCE, must measure.
11. Platform risk: MEDIUM (GitHub API + model dependence; workflow + history stickiness defends).
12. Time-to-MVP: 4–6 weeks. 13. $100 MRR: $49 × 3 teams.
14. Strongest evidence: 2M repos + per-seat grievance threads (FACT-pattern).
15. Strongest counterevidence: context-window costs at flat pricing can invert margins; incumbents ship weekly.
16. Verdict: **BUILD** → Phase 02 with quota/BYOK margin proof as Gate-07 prerequisite.
