# Idea — Tender/RFP Form-Fill Assistant

- Category: AI/HYBRID. Track: HYBRID. Date: 2026-09-12.
- User: nonprofits/agencies retyping the same data into tender portals.
- Problem: every RFP re-asks profile data; no memory across portals.
- Workaround: text-expander snippets, copy-paste libraries.
- Alternatives: Loopio ($20k/yr enterprise), manual.
- Wedge: stored org profile + portal-form fill assist, $29/mo; unlock test = one template working end-to-end.
- MVP (experiment): single-portal fill demo + profile store. Build: 2–3 days. Upfront: $0. Variable: ~$0.03/use, capped.
- Distribution: nonprofit ops forums, agency communities, IH feedback.
- Hypothesis: one working template unlocks willingness (measured: completed fills).
- Success: 20 completed fills + 3 pay-intent replies. Kill: <5 fills.
- $100 MRR path: $29 × 4 orgs → agency workflow SaaS.
- Uncertainty: portal variance (each portal a special case — scope risk).
- Why track: profile-memory wedge vs Loopio enterprise; unlock test is crisp. Confidence: LOW-MEDIUM (honest).
