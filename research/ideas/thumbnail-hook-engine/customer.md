# Customer — Outlier Thumbnail Engine

## PRIMARY USER

Weekly-uploading 10k–500k-sub long-form English YouTuber currently assembling packaging from vidIQ + ViewStats + spreadsheets + designer.

## PRIMARY BUYER

Same creator (card-in-hand, no committee) — IF the tool earns a slot in the weekly workflow.

## SECONDARY USER

Smaller/niche creators (sub-10k, Shorts-first, non-English, podcasters) — hypothesized, zero pay evidence.

## Profile

- Job-to-be-done: decide this week's title + thumbnail fast, with evidence.
- Trigger: upload day; CTR slump; competitor video popping.
- Workflow: outliers → decode → remix → native test (above).
- Frustration: tool sprawl, credit ceilings, thin niche data, learning curves.
- Desired outcome: videos that get clicked — an OUTCOME, not a tool (see below).
- Current workaround: free-tool stack + designer spend ($20/thumb anchor).
- Buying trigger: sustained uploading + demonstrated time-save (1of10's own qualification).
- Objections: "tools can't make people like my videos" (verbatim); price vs free stack; learning curve; niche coverage.
- Willingness-to-pay evidence: PROVEN at $69–89 for the served segment (1of10); UNPROVEN for any new $29 entrant or niche.
- Acquisition channel: educator affiliates or Reddit grind (INFERENCE; conversions unobserved).

## The analysis-vs-clicks distinction (owner's key question — ANSWERED)

Buyers pay for TIME-SAVED OUTLIER DISCOVERY (analysis tool), evidenced by 1of10 retention logic ("worth it if you upload weekly and decide from data") — but they WANT more clicks (outcome), evidenced by churn-when-no-lift and "don't expect the tool to grow your channel" threads. Product consequence: the MVP must sell and deliver a weekly idea pipeline (discovery throughput), never "more views" — and retention structurally depends on the creator's own growth, which the tool doesn't control. That dependence is the retention threat documented in decision.md.
