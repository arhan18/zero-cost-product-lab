# MVP Patterns (indie-business corpus)

First-version reconstructions + deliberately-not-built lists, per record (`initialMVP`, `featuresNotInMVP`, `timeToLaunch`).

## TOP 20 MVP patterns

1. Nights-and-weekends builds on salary (Gymdesk→$3M ARR, HelpSpot, Invoice Ninja).
2. Internal-tool-turned-product (Bonjoro, Better Proposals, Dubsado agency origins; LogSnag lineage in sibling corpus).
3. No-code MVP (Evaboot → $2M ARR; Formula Bot ~$50 v1 + Bubble).
4. Single-feature wedge (Dead Man's Snitch: one ping; Healthchecks: one check; Bear Blog: one paid feature — custom domains → $2K/mo in weeks).
5. Manual service first (concierge onboarding before automation — several k03/k07 records).
6. Open-source core + paid hosting (Healthchecks, TastyIgniter, Invoice Ninja).
7. Pre-sell before build (several k05/k09 records: $400 MRR in 9 days; first sale in 5 minutes).
8. Audience-first launch (Taplio reusing Tweet Hunter code + influencer board; Hypefury audience).
9. Directory/listing MVP (curated list before platform — k10-adjacent pattern).
10. Wrapper-first, moat-later (Chatbase, Numerous.ai maintenance-mode).
11. Docs/blog as MVP surface (ConfigCat AlternativeTo listing as first funnel).
12. Lifetime-deal launch (Plutio, Docsketch — cash + learning, overhang later).
13. Solo desktop builds, zero infra (Dash, SnippetsLab, Kaleidoscope lineage).
14. Mobile-first only where the job demands it (Goldie/Appointfix, Time To Pet).
15. Integration, not platform (Bannerbear-style API wedges; Evaboot LinkedIn post validation).
16. Copy-then-niche (Taplio cloning Tweet Hunter codebase for LinkedIn).
17. Sunset-scope discipline (Numerous.ai deliberately entering maintenance mode).
18. Externally-funded MVP honestly labeled (Hello Audio Techstars; Sudowrite $3M angels — kept as contrast records).
19. Failure-shaped MVPs (Pagoda Box: right product, converged-away category; Espresso: handoff not scale).
20. Accidental demand (products that started as free tools/audiences and discovered willingness-to-pay — Bear Blog, Ko-fi).

## Deliberately NOT built (recurring)

Teams/collaboration, mobile apps, analytics dashboards, admin UIs, i18n, SOC2, usage-based billing v1, AI features before distribution. Added only on paying-customer demand.
