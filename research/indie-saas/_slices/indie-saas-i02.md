## Typedream (https://typedream.com)

- **Evidence grade:** FACT
- **Category:** Website builder / no-code / creator tooling
- **Founder:** Kevin Chandra (CEO), Anthony Christian, Albert Purnama (CTO) — YC W20, team of 5
- **Launched:** 2020 (YC Winter 2020); **Status:** Acquired by beehiiv (June 2024)

**Revenue / money:** No revenue published as a standalone company. Records show $650K total funding (YC + angels Aadil Mamujee, Ben Tossell, Blaine Cook, Timothy Lee) and an acquisition exit to beehiiv (deal value undisclosed). Not a bootstrapping case study — a YC incubation case.

**MVP:** "Easy as Notion, pretty as Webflow" — a no-code AI website builder where you type an idea and it generates structure, copy, and styling. Founded in 2021 by five college grads; product launched out of YC W20.

**Distribution & launch:** Launched via YC, went #1 Product of the Month on Product Hunt (July 2021); positioned against Webflow on simplicity; built a creator following (135K websites created, 2,000+ link-in-bios claimed). beehiiv acquired it in 2024 to bring its AI website-building tech into its newsletter platform; founders now run "The Prompting Company" (AI visibility).

**Contradictions:** Tracxn lists Putri Karunia/Michelle Marcelline as co-founders while YC lists Kevin Chandra/Anthony Christian/Albert Purnama — a 5-person founding team with differing founder lists across sources. CB Insights says "founded 2021"; YC says 2020. Treat founding year as 2020 (W20 cohort). Factsheet: this is a VC-funded startup, not a zero-dollar product.

## DevHints (https://devhints.io)

- **Evidence grade:** FACT (but not a monetized SaaS)
- **Category:** Developer documentation / cheatsheet library
- **Founder:** Rico Sta. Cruz (@rstacruz)
- **Launched:** 2012; **Status:** Active free open-source project

**Revenue / money:** UNKNOWN — no monetization published. Entirely free, no account required, static Markdown site.

**MVP:** A personal collection of cheatsheets for tools the author used, published as an open-source GitHub repo (`rstacruz/cheatsheets`, created March 2012) and rendered into a static site. Grew to 357+ curated cheatsheets, 14.5K GitHub stars, 3.6K forks.

**Distribution & launch:** Grew organically from the author's reputation as an OSS maintainer + SEO/organic search + GitHub Stars. No structured launch. Monetization mountain remains unexplored.

**Contradictions / blind spot:** This is a content/library project, not a SaaS with revenue — included because the user flagged it as a candidate. It illustrates the gap between "collection with audience" and "business with revenue"; ideal as a content asset for a larger tool rather than a standalone $100 MRR product.

## Plausible Analytics (https://plausible.io)

- **Evidence grade:** FACT
- **Category:** Web analytics / privacy / open-source SaaS
- **Founder:** Uku Taht (dev, first code Dec 2018) + Marko Saric (marketing, joined Mar 2020) — team of 4
- **Launched:** 2018; **Status:** Active, bootstrapped, profitable, open-source (AGPL)

**Revenue / money:** Self-reported and transparent: $500K ARR (Oct 2021, ~$42.6K MRR), $1M ARR (June 2 2022, $83,637 MRR, 7,000+ subscribers, 50,000+ sites, 1B+ monthly pageviews). Third-party estimate ~$3.1M ARR 2024 (GetLatka). Pricing tiered by pageviews from ~$9/mo (up to 10k pageviews); free 30-day trial, no credit card; self-hosted OSS free.

**MVP:** Uku wrote the first line of code Dec 2018, public beta Jan 2019, paid subscriptions May 2019 at $64 MRR, open-sourced Sept 2019. Growth was bootstrapped — the founders went months without salaries and burned ~$50K in savings before becoming sustainable.

**Distribution & launch:** Canonical "picking a fight" playbook — first customers from Indie Hackers, growth exploded from the "Stop using Google Analytics" post (Apr 2020, 50K+ readers in days), then rode GDPD/GDPR-violation and "Google kills GA" news waves (Jan/Mar 2022). Product Hunt Aug 2020. $0 paid advertising; built almost everything in public.

**Contradictions:** None material. GetLatka ARR is a third-party estimate vs. self-reported milestones. This is the strongest "zero-cost, open-source, public-in-public" blueprint in this slice.

## SiteGuru (https://siteguru.co)

- **Evidence grade:** FACT (product, bootstrapping, pricing, self-reported revenue trajectory)
- **Category:** SEO audit / technical SEO tool for non-experts
- **Founder:** Rick van Haasteren (solo, Netherlands)
- **Launched:** 2017/2018; **Status:** Active, bootstrapped, "funded by our customers"

**Revenue / money:** Self-reported: $400 MRR at first public sharing → ~$2K MRR (prior year) → ~$12K MRR (StarterStory, Apr 2025) → $14K MRR (IndieHackers, Oct 2025). Pricing: Small $49/mo (5 websites), Medium $99/mo (15 sites), Large $199/mo (50 sites); free trial, no credit card, no permanent free plan; also sells an AppSumo-style lifetime tier as a revenue booster.

**MVP:** Started as an internal tool Rick used freelancing for SEO clients (a "free SEO tool" that audited one page, or whole site with an account), providing an easy-to-understand prioritized SEO to-do list + connections to Google Analytics/Search Console. During the pandemic he quit his job and went full-time.

**Distribution & launch:** Consultant-to-product transition done right: first N users were Rick's own clients. Content/SEO (academy, glossary), G2/Capterra growth ("Easiest to use on Capterra", "Top SEO Software 2025"), Indie Hackers, early AdWords, AppSumo lifetime deals. Now checks ~8,000 websites weekly for ~5,000 site owners.

**Contradictions:** Launch date varies (2017/2018 per blog vs "started January 2018" StarterStory vs "founded 2021" Tracxn = company registration). Revenue varies $12K (StarterStory) vs $14K (IndieHackers). Grade revenue as INFERENCE unless corroborated.

## Umami Analytics (https://umami.is)

- **Evidence grade:** FACT (existence, open-source, pricing, funding)
- **Category:** Web analytics / privacy / open-source (+ Umami Cloud)
- **Founder:** Mike Cao (CEO), Brian Cao, Francis Cao (co-founders)
- **Launched:** 2020 (open source); **Status:** Active — open-source project + paid Umami Cloud

**Revenue / money:** No published revenue/ARR. Company raised $1.5M pre-seed (Race Capital-led, July 2022). Pricing: Hobby $0/mo (up to 100K events, 1 website, 6-month retention), Pro $20/mo (1M events, 20 sites, 2-yr retention, API), Business $200/mo (10M events, session replays, heatmaps, white-labeling), Enterprise custom. Free tier, no credit card; 14-day trial on paid.

**MVP:** An open-source, self-hostable, cookieless analytics dashboard; grew via GitHub community (38K+ stars, 100+ contributors, 4M+ downloads by Aug 2022); monetization added later via hosted Umami Cloud on top of the OSS project.

**Distribution & launch:** Open-source-first / community-led growth, developer word-of-mouth, GitHub stars, docs SEO. Strong "analytics alternatives" SEO presence.

**Contradictions:** **Not bootstrapped** — VC-backed ($1.5M pre-seed), so it breaks the strict zero-cost premise; flag as an exception/reference model for "OGL subtle Monetize the self-host + free tier" rather than a pure bootstrapped case. Free-tier limits vary by source (umami.is says 1 website; FreeTier.co claims 3).

### Disoveries
- **Plausible** is the canonical zero-cost blueprint: open source, self-funded, transparent ARR, "picking a fight" blog posts, $0 paid ads.
