## 1. Tokens
- Color: semantic + primitive values; every color has a rationale (§6).
- Typography: family pairs (display/body), scale, weights; intentional choices.
- Spacing scale, radius, shadows, motion durations/easings.

## 2. Core components
Button, input, card, nav, modal (+ whatever the UX doc needs). Each:
- spec (states, sizes, spacing),
- adapted to this product's visual language —
  **never a stock component-library demo pasted unchanged** (SYSTEM.md §19).

## 3. Usage rules
Do/don't for applying tokens; hardcoded hex outside tokens = error.

## 4. Accessibility baseline
Contrast, focus, tap targets, reduced-motion — carried into Phase 16.
