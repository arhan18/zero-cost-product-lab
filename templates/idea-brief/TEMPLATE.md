# Template — Idea Brief

Used in **Phase 01 (Idea Discovery)**. One file per idea. Raw feed items, not yet validated. Tag suspicion honestly.

## IDEA BRIEF

| Field | Value |
|---|---|
| Title (one line) | helps [person] do [task] |
| Source of idea | (own pain / forum / trend / competitor gap / …) |
| Source URL / date | |
| Tag (product or "unknown") | |
| Suspicion level | HIGH / MEDIUM / LOW — how strongly we currently believe demand exists |

## Body

- **The problem** (as the sufferer would describe it — quote if you have a real quote).
- **Who feels it** (specific, not "everyone").
- **Today's workaround** (what people do instead).
- **Would they pay / would they use it freely first?** (HYPOTHESIS until proven.)
- **Notes** (anything else, flagged FACT / INFERENCE / HYPOTHESIS / UNKNOWN).
