## 1. Target keywords
Term a target user would type → mapped to a page we ship. Mark solo-keyword interest as INFERENCE, not FACT.

## 1b. Ownable queries (Phase-15 gate)
Can this product realistically OWN a searchable query/category/intent? Name 1–3 ownable queries with why-we-can-win-each. If none: SEO is not the channel — say so and pick another. Never build generic keyword pages to inflate page count.

## 2. On-page
- Title / meta per page (own words, honest).
- Heading hierarchy, single H1, descriptive links.
- Sitemap + robots.

## 3. Content plan
What pages exist beyond the tool (help/landing) that match real search intent.

## 4. Technical
Canonicals, indexing policy, structured data where genuinely relevant (skip if speculative).

## Rule
Every search term we chase maps to a real page that honestly delivers. No keyword-stuffed pages, no invented claims.
