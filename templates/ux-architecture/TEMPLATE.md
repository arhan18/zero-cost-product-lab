## 1. Core flow
- Flow diagram (text/mermaid) from first touch to "done".
- The kill point: the one step where a new user might give up.

## 2. Screens / states inventory
For each screen: purpose, primary action, secondary actions.
Include explicit **empty / loading / error / repeat-use** states.

## 3. Information hierarchy
What the user sees first, second, third — and why.

## 4. Decisions & language
- Terminology the user already uses (from customer research, quoted).
- Confirmation/undo for destructive actions.

## Quality bar
A new user can complete the core promise after reading only this document.
